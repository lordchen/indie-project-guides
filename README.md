# Independent project guides

These are projects I maintain. This repository contains usage notes, not the applications’ source code.

## ImageVerify — AI image screening

[Open ImageVerify](https://imageverify.deepquestai.org/) · [Open the image detector](https://imageverify.deepquestai.org/en/ai-generated-image-detector/)

Upload an original JPG, PNG or WebP, run verification, and review the score together with the evidence. Use the result as a screening signal before sharing or publishing an image.

A detector score cannot prove whether an image is real or synthetic. Check the original source, provenance and context too. Images are uploaded for processing; this is not an offline tool. Avoid uploading sensitive identity, medical or legal files.

## Burn Subtitles — put subtitles into a video

[Open Burn Subtitles](https://burnsubtitles.com/)

1. Choose a video in your browser.
2. Import an SRT or VTT subtitle file, or enter subtitles manually.
3. Adjust the appearance, preview, burn the subtitles, and download the result.

Video processing runs locally in the browser. It does not automatically transcribe speech; prepare the subtitle text first. Processing speed and practical file limits depend on your device and browser. Keep your original video and subtitle file so you can revise the text later: burned-in subtitles are part of the output image.

## Hello Shenzhen — plan a tech day trip

[Open Hello Shenzhen](https://helloshenzhen.deepquestai.org/) · [Shenzhen tech tour planning](https://helloshenzhen.deepquestai.org/shenzhen-tech-tour/) · [Hong Kong to Shenzhen day trip](https://helloshenzhen.deepquestai.org/guides/hong-kong-to-shenzhen-day-trip/)

Use the route guides to choose a manageable area, compare transport options, and plan time and budget. The site provides planning information, a PDF and a private summary; it is not a confirmed guided-tour booking.

Check current opening hours, transport schedules, entry requirements and availability with the relevant official providers before travelling.
